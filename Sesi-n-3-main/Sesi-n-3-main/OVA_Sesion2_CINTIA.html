🧮 ¿Qué es DAX?

DAX (Data Analysis Expressions) es el lenguaje de fórmulas de Power BI que permite crear cálculos personalizados, medidas calculadas y columnas calculadas. Es similar a las fórmulas de Excel pero mucho más potente.

📝 Componentes de DAX

  • Medidas: Cálculos dinámicos que se evalúan en tiempo de ejecución
  • Columnas calculadas: Columnas nuevas que se calculan durante la carga de datos
  • Tablas calculadas: Tablas completas derivadas de datos existentes
  • Funciones: Más de 250 funciones para diferentes propósitos analíticos
-- Sintaxis básica de DAX
NombreMedida =
FUNCION(
Tabla[Columna],
Filtro
)

🔧 Funciones Fundamentales

CALCULATE

La función más poderosa de DAX

CALCULATE(Expresión, Filtro1, Filtro2...)

Modifica el contexto de filtro de una expresión

FILTER

Filtra tablas según condiciones

FILTER(Tabla, Condición)

Devuelve una tabla con filas que cumplen criterios

SUMX / AVERAGEX

Funciones de iteración (X)

SUMX(Tabla, Expresión)

Evalúa expresión fila por fila

RELATED

Accede a datos de tablas relacionadas

RELATED(Tabla[Columna])

Obtiene valores de tablas relacionadas

📅 Inteligencia de Tiempo

  • DATEADD: Suma/resta períodos de tiempo
  • SAMEPERIODLASTYEAR: Mismo período del año anterior
  • TOTALYTD: Acumulado año hasta la fecha
  • DATESBETWEEN: Rango de fechas específico

📊 Creación de Medidas

Las medidas calculadas son fórmulas DAX que se evalúan dinámicamente según el contexto de filtros seleccionados por el usuario. Son fundamentales para crear KPIs y métricas de negocio.

🎯 Ejemplos de Medidas Comunes

-- Total de Ventas
Total Ventas = SUM(Ventas[Importe])
-- Ventas del Año Actual
Ventas Año Actual = CALCULATE( [Total Ventas], Calendario[Año] = YEAR(TODAY()) )
-- Crecimiento YoY
Crecimiento YoY = DIVIDE( [Ventas Año Actual] - [Ventas Año Anterior], [Ventas Año Anterior] )

💡 KPIs y Formato Condicional

  • Usar medidas para crear indicadores clave de rendimiento
  • Aplicar formato condicional basado en umbrales
  • Combinar múltiples medidas en KPIs compuestos
  • Utilizar iconos y colores para visualización rápida

Actividades prácticas

🧮 Simulación 2: Crear Medidas DAX

Instrucciones: Completa las fórmulas DAX seleccionando la función correcta.

Medida 1: Total de ventas con filtro de año

Ventas 2023 = (SUM(Ventas[Importe]), Calendario[Año] = 2023)

Medida 2: Promedio por categoría

Promedio Categoría = (VALUES(Productos[Categoría]), CALCULATE(SUM(Ventas[Importe])))

Medida 3: Ventas de productos top

Ventas Top = (SUM(Ventas[Importe]), FILTER(Productos, Productos[Categoria] = "Top"))

Medida 4: Crecimiento interanual

Crecimiento YoY = ([Ventas 2023] - [Ventas 2022], [Ventas 2022])
