🎨 Principios de Diseño del Informe

La ciencia y el arte de comunicar datos visualmente requiere seguir principios fundamentales que guíen el ojo del lector de forma natural.

💡 Principio clave: «Menos es más»

Simplicidad y claridad sobre cantidad de elementos. El diseño debe guiar al ojo del lector de forma natural.

� Principios Fundamentales

  • Ubicación: Posición estratégica de elementos para jerarquía visual
  • Equilibrio: Distribución armónica del peso visual
  • Contraste: Diferenciación clara entre elementos importantes
  • Proximidad: Agrupación de elementos relacionados
  • Repetición: Consistencia en estilos y patrones
  • Regla de los tercios: División del espacio en 9 partes iguales
  • Proporción áurea: Relación matemática 1.618 para diseño estético

🧩 Elementos del Informe (no de datos)

📝 Cuadro de Texto

Añade texto enriquecido, títulos e hipervínculos. Puede incrustar valores dinámicos del modelo (se filtra con la página = actúa como visual).

→ Narración Inteligente: resume datos automáticamente

🔘 Botones

Acciones: navegar páginas, drill-through, marcadores, abrir URL, preguntas frecuentes o volver atrás. Hacen el informe más interactivo (tipo app).

⭐ Formas

Decoración o comportamiento de botón. Formas básicas, flechas, corazones y más. Admiten texto y múltiples estilos visuales.

🖼️ Imágenes

Cargar logo o ilustración (BMP, JPEG, GIF, TIFF, PNG). Pueden comportarse como botones. Ayudan a la identidad visual del informe.

⚠️ Importante: Seleccionar el tipo incorrecto puede dar lugar a representaciones incorrectas. Elige bien según el tipo de dato y el espacio.

💡 Nota clave:

Ordena los gráficos de categoría por valor (↑ o ↓), no alfabéticamente. Usa líneas solo para datos temporales con flujo continuo — nunca para categorías.

📋 Reglas Clave para Cada Tipo de Visual

📊 Barras / Columnas
  • • Ordena por valor descendente (salvo secuencia lógica)
  • • Evita leyendas de color con muchas categorías
  • • Nunca uses gráfico de líneas con eje X de categorías
📈 Series Temporales
  • • Usa siempre líneas o columnas con eje X = tiempo (izq→der)
  • • Con huecos de datos prefiere columnas (evita tendencias falsas)
  • • Puedes añadir previsión como opción de análisis
🥧 Proporcionales
  • • Barras/columnas 100% apiladas para múltiples dimensiones
  • • Solo valores todos positivos o todos negativos
  • • Área amplia → barras horizontales; estrecha → columnas
�️ Geoespaciales
  • • Datos por ciudad → Mapa de burbujas (puntos)
  • • Datos por estado/región → Mapa coroplético (relleno)
  • • Ocupan mucho espacio: evalúa si la ubicación es realmente relevante

🔍 Jerarquía de 5 Niveles de Filtrado

La complejidad aporta control. 5 niveles de filtrado disponibles. Cada nivel hereda los filtros del nivel superior.

1
Filtros de modelo: Aplican a todo el modelo de datos
2
Filtros de todas las páginas → nivel INFORME (global)
3
Filtros de esta página → nivel PÁGINA (suma a los de informe)
4
Filtros de este objeto visual → nivel VISUAL (suma a los anteriores · acepta medidas)
5
Filtros de medida: Aplican dentro de fórmulas DAX

⚙️ Panel Filtros: Tipos y Opciones Avanzadas

📋 Tipos de Filtro disponibles:
  • Básico: Selección directa de valores del campo
  • Avanzado: Condiciones con operadores por tipo de dato
  • N Principales: Top/Bottom N por valor de medida
  • Fecha / Hora Relativa: 'Últimos 7 días', 'Este mes', etc.
🔒 Controles de Administración:
  • Bloquear filtro: Los consumidores no pueden quitar ni modificar el filtro. Recomendado para filtros críticos del diseño
  • Ocultar filtro: El filtro existe y actúa, pero el consumidor no lo ve. Útil para limpiar datos en segundo plano
  • Ocultar Panel: El panel Filtros completo queda inaccesible para el consumidor final del informe

💡 Nota importante: Una segmentación NO es un filtro de página: es un visual que propaga filtros. Diferencia clave para entender el comportamiento del informe.

🎛️ Segmentadores (Slicers): Tipos y Configuración

El visual de filtro más intuitivo y visible para el usuario final

📐 Tipos de Segmentadores:
  • • Lista vertical
  • • Lista horizontal
  • • Mosaico
  • • Dropdown
  • • Tarjetas
  • • Rango (para fechas y números)
⚙️ Configuraciones clave:
  • • Sincronización entre páginas
  • • Selección única vs múltiple
  • • Mostrar elementos con datos
  • • Orden personalizado

⚠️ Importante: La orientación HORIZONTAL muestra todos los valores visibles — ideal para pocas categorías. Evítala con muchos valores pues los usuarios no ven la barra de desplazamiento.

💻 Tipos de Informes según el Público

Cada tipo requiere un enfoque diferente de UI/UX

🏢 Panel Ejecutivo

Alta nivel, KPIs clave, mínima interactividad

📊 Informe Analítico

Detallado, múltiples filtros, alta interactividad

👥 Informe Operativo

Datos en tiempo real, acciones específicas

💡 Recuerda: El tipo de informe determina cuánta interactividad se expone al usuario. Un panel ejecutivo no debe tener segmentadores complejos; un informe analítico sí.

🖥️ Power BI Desktop: Partes Clave de la Interfaz

Conoce el entorno antes de construir visualizaciones

📌 Componentes principales:
  • • Cinta de opciones: Herramientas y funciones
  • • Barra de navegación: Vista, Datos, Modelo
  • • Lienzo: Área de diseño del informe
  • • Panel Visualizaciones: Tipos de gráficos
  • • Panel Datos: Campos y medidas
  • • Panel Filtros: Configuración de filtros
🎯 Flujo de trabajo:
  • 1. Conectar a datos
  • 2. Transformar y modelar
  • 3. Crear visualizaciones
  • 4. Configurar interactividad
  • 5. Formatear y publicar

💡 Recuerda: Desde la Vista Informe: el lienzo central es donde creas y organizas los visuales. Panel Visualizaciones (derecha) para elegir tipos. Panel Datos (derecha) para los campos.

🔄 Flujo de Creación de Visualizaciones

Pasos algorítmicos para agregar gráficos al informe

📊 Gráfico de Columnas
  1. ① Icono columnas apiladas
  2. ② Eje: Fecha (solo Mes)
  3. ③ Valores: Coste Total
  4. ④ Redimensionar arriba-izquierda
📈 Gráfico de Líneas
  1. ① Icono líneas
  2. ② Eje: Fecha (Mes/Día)
  3. ③ Valores: Materiales, Impresión, Ensamblado, Envío
  4. ④ Colores por tema
📊 Gráfico de Área Apilada
  1. ① Icono área apilada
  2. ② Eje: Fecha
  3. ③ Valores: Coste Producción + Envío
  4. ④ Eje Y inicio = 0 para no distorsionar

⚙️ Interactividad, Formato y Guardado

💰 Formato de Datos como Divisa

Selecciona el campo en Panel Campos → pestaña Herramientas de columna → ícono Divisa.

Repite para cada campo numérico (Materiales, Impresión, Ensamblado, Envío, Coste Total).

🔗 Filtro Cruzado entre Visuales

Clic en un punto de datos de un visual → los demás visuales se ajustan automáticamente.

Clic en el mismo punto para revertir. Puedes configurar las interacciones: filtrar, resaltar o ninguno.

💾 Guardar y Compartir
  • Guardar .pbix: Archivo → Guardar como → introduce el nombre. Power BI usa extensión .pbix para todos sus archivos guardados. Contiene modelo, relaciones, visuales y medidas en un solo archivo.
  • Publicar: Publicar → selecciona área de trabajo → disponible en app.powerbi.com
  • Compartir: Compartir enlace o insertar en Teams / SharePoint

🚀 Explorar y Compartir: A medida que agregas tablas, los informes se vuelven más complejos e interactivos.
